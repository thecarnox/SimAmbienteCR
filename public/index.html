Consentimiento informado

Protección de datos personales — Ley N.º 8968

Para utilizar SimAmbienteCR, se requiere recopilar información personal necesaria para gestionar su experiencia educativa.

Finalidad de los datos

Identificar al jugador, almacenar las puntuaciones y recuperar el progreso de las actividades educativas. La información recopilada será utilizada únicamente para fines académicos.

Almacenamiento y privacidad

La información será almacenada en una base de datos alojada en un servidor con mecanismos de seguridad y no será utilizada con fines comerciales.

Derechos del usuario

El usuario podrá solicitar el acceso, rectificación o eliminación de sus datos personales y revocar su consentimiento.
